# 奶蛙入塘登记处（本地测试）

使用 Node.js 24.16 或更新版本，无需安装 npm 依赖。在仓库根目录运行：

```sh
node backend/server.mjs
```

访问 `http://127.0.0.1:8765/`。这个进程同时提供网站和 `/api/enrollments` 接口，仅监听本机。不要通过直接打开 HTML 或普通静态文件服务器测试入学功能。

## 数据

- 默认数据库为 `.local/students.sqlite`，已加入 Git 忽略。不同浏览器使用同一份名册；刷新、关闭浏览器和重启服务都不会清空记录。
- 蛙号为 3–20 位字母、数字、下划线或短横线。全角字符归一化后统一转成大写，数据库唯一约束保证不重复。
- 蛙名为 1–20 个字。只公开头像、蛙名、蛙号和入学／毕业年份。
- 入学年份固定为蛙元 0 年，毕业年份固定为蛙元 4 年；客户端不能修改。
- 同一次登记的网络重试使用相同请求凭据，避免重复计数。名册按最近入学顺序分页。

可以使用 `NAIWA_PORT` 修改端口，使用 `NAIWA_DATABASE_PATH` 指定独立测试数据库。请保留数据库文件；备份时先停止服务，再复制数据库。

## 验证

```sh
node --test backend/registry.test.mjs
```

测试覆盖唯一性、并发登记、网络重试幂等、重启持久化、分页和数据库文件保护。浏览器验证另外覆盖表单、头像、跨浏览器查询、丢失响应重试、移动端与减少动态效果。

## 线上共享登记

GitHub Pages 继续托管前端及现有域名。线上入学接口运行在 Sites 的 Cloudflare Worker，数据由 D1 持久保存。项目身份、接口地址与对应源码提交见 `cloud/deployment.json`；核心服务和迁移快照见 `cloud/`，完整源码保存在该 Sites 项目的源仓库。

首页的 `naiwa-enrollment-api` 指向共享接口。localhost / 127.0.0.1 仍自动使用独立本地数据库，试填记录不会混入线上。不要提交 `.local/` 数据或把它导入生产数据库。

线上新增短期匿名登记凭据、来源检查和提交频率限制。蛙号与请求凭据均由数据库唯一约束保护；并发重复登记返回 409，原请求重试返回原记录。前端每30秒刷新人数，展开或刷新名册时获取当前共享记录。

前端静态资源发布不会重建或清空数据库。后端更新必须通过同一 Sites 项目并追加迁移；维护密钥只在 Sites 运行时保存。回退前端不影响已有登记数据。
